			Приложение для работы с яндекс музыкой


Описание:

приложение, которое позволяет искать треки, добавлять их в избранное, создавать плей-листы.






			- Запуск и работа с приложением -



*Установить зависимости (requirements.txt):

pip install -r requirements.txt


* Обновить pip (если понадобится)
python -m pip install --upgrade pip



* Запустить приложение через CMD:
 Диск:\Путь\app>python app.py

После этого появится информация, что: YANDEX MUSIC PLAYER ЗАПУЩЕН.
Далее в браузере необходимо перейти на: http://127.0.0.1:5000 и авторизоваться через Яндекс.
После нажатия на кнопку: "Войти" - "Войти через Яндекс" в CMD появится ссылка и код.
После авторизации бедет доступно приложение, котором возможно искать треки, добавлять в избранное, создавать плей-листы.
Для остановки работы приложения в CMD необходимо выполнить команду: "Ctrl + C"
